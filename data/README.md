# Data README

## Public dataset

- `data/mental_health_digital_behavior_data.csv`
  - Dataset canonico de entrenamiento para este proyecto.
  - Es el archivo usado en la version reorganizada de Fase 2.

## Private dataset (excluded from version control)

- `private-data/form_responses.csv` (gitignored)
  - Contiene respuestas de formulario con posibles datos personales.
  - No se incluye en control de versiones por privacidad.
  - Para usarlo localmente, cada colaborador debe colocarlo manualmente en `private-data/`.

## Privacy notes

- No publicar archivos con correos u otros identificadores personales.
- Si se comparte una muestra, debe estar anonimizada y libre de PII.
